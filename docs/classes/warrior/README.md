# 战士：技能与天赋

[职业总览与通用规则](../README.md) · [项目首页](../../../README.md#职业介绍)

以顺劈斩开局，擅长近身多目标输出。雷霆一击和挫志怒吼降低贴身压力，
斩杀收割残血普通敌人；不需要照搬原版的怒气循环。

## F：冲锋

局内 5 级解锁，基础冷却 **8 秒**。冲向 25 码内目标并眩晕 1.5 秒；
有鼠标瞄准位置时优先选择靠近瞄准点的敌人，没有目标则朝方向突进半程。
不是自动释放技能。

## 局外天赋

武器、狂怒、防护各 8 个节点，共 24 个；最多 51 点，免费重置，下一局生效。
普通节点最多 5 点，终极节点最多 1 点；每树阶层依次为 0、0、1、2、3、4、5、6，
第 n 阶要求本树更低阶累计投入 5n 点。下表序号对应源码索引，5 点节点的效果均为**每级**数值。
冷却最终不低于 0.2 秒；控制时长修正与装备共用 50% 加成上限。

## 构筑建议

- **贴身清群**：顺劈斩、旋风斩、横扫攻击，配范围、伤害和生存属性。
- **控制收割**：雷霆一击、挫志怒吼、斩杀，用减速和减伤创造近战空间。
- 技能词缀可考虑顺劈斩的额外目标、旋风斩的半径；斩杀的秒杀阈值不适用于首领。

建议是已有机制的组合，不是额外套装效果，也不保证选卡必定出现。
