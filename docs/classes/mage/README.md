# 法师：技能与天赋

[职业总览与通用规则](../README.md) · [项目首页](../../../README.md#职业介绍)

以寒冰箭开局，拥有冰霜控制、火焰爆发、奥术近身清群及地面法术。
多数攻击自动选择目标，走位与闪现比手动施法循环更重要。

## F：闪现术

局内 5 级解锁，基础冷却 **10 秒**。朝鼠标方向瞬移最多 **18 码**，
无有效瞄准位置时朝面向方向；位置受战场边界限制。

## 局外天赋

奥术、火焰、冰霜各 8 个节点，共 24 个；最多 51 点，免费重置，下一局生效。
普通节点最多 5 点，终极节点最多 1 点；每树阶层依次为 0、0、1、2、3、4、5、6，
第 n 阶要求本树更低阶累计投入 5n 点。下表序号对应源码索引，5 点节点的效果均为**每级**数值。
炎爆术、冲击波仍可直接从局内技能池获得，不需要原版天赋解锁。
“火焰主要直伤”仅指火球术、火焰冲击、炎爆术和冲击波，不包括烈焰风暴地面跳伤、点燃或炎爆术跳伤。
“冰霜主要直伤”仅指寒冰箭、冰霜新星和冰锥术；暴风雪不获得碎冰，也不消耗寒冰指层数，
但可触发寒冰指，每次脉冲最多判定一次。所有主要直伤触发均不包括追加命中。
冷却最终不低于 0.2 秒，控制时长修正与装备共用 50% 加成上限，暴击率最终不超过 100%。

## 构筑建议

- **冰霜控场**：寒冰箭、冰霜新星、暴风雪、冰锥术，控制持续时间和范围强化有价值。
- **火焰清群**：火球术、烈焰风暴、炎爆术，兼顾溅射、区域伤害和高生命目标。
- **近身脱围**：魔爆术、冲击波与闪现组合；不要把控制当成对首领的永久限制。
