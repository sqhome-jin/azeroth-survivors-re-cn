# 猎人：技能与天赋

[职业总览与通用规则](../README.md) · [项目首页](../../../README.md#职业介绍)

以奥术射击开局，依靠射程、多目标射击、陷阱与减速进行风筝。
当前没有需要控制或培养的宠物系统。

## F：猎豹守护

局内 5 级解锁，基础冷却 **14 秒**，移动速度提高 **70%**，持续 **5 秒**。
这是手动限时加速，不是永久切换的守护。

## 局外天赋

野兽控制、射击、生存各 8 个节点，共 24 个；最多 51 点，免费重置，下一局生效。
普通节点最多 5 点，终极节点最多 1 点；每树阶层依次为 0、0、1、2、3、4、5、6，
第 n 阶要求本树更低阶累计投入 5n 点。下表序号对应源码索引，5 点节点的效果均为**每级**数值。
**野兽控制强化猎人自身，不召唤、不要求宠物**；也不引入弹药系统。
“主要射击”指奥术射击、多重射击、瞄准射击、震荡射击的主要直接伤害，不包括持续伤害或追加命中。
冷却最终不低于 0.2 秒，控制时长修正与装备共用 50% 加成上限。

## 构筑建议

- **远程清群**：多重射击、乱射、爆炸陷阱，配额外目标或范围强化。
- **持续风筝**：毒蛇钉刺、震荡射击，加速期间绕敌群移动。
- **高血量目标**：瞄准射击配直伤、暴击和冷却；注意它优先生命较高的目标，并非手动锁定首领。
