# 德鲁伊：技能与天赋

[职业总览与通用规则](../README.md) · [项目首页](../../../README.md#职业介绍)

以愤怒开局，结合自然/奥术直伤、持续伤害、缠绕和自我恢复。
当前技能池没有熊、猎豹或枭兽形态战斗分支。

## F：急奔

局内 5 级解锁，基础冷却 **15 秒**，移动速度提高 **80%**，持续 **4 秒**。
当前不要求先变形为猎豹，也不自动赋予形态战斗能力。

## 局外天赋

平衡、野性战斗、恢复各 8 个节点，共 24 个；最多 51 点，免费重置，下一局生效。
普通节点最多 5 点，终极节点最多 1 点；每树阶层依次为 0、0、1、2、3、4、5、6，
第 n 阶要求本树更低阶累计投入 5n 点。下表序号对应源码索引，5 点节点的效果均为**每级**数值。
**野性战斗强化荆棘、定身和急奔，不引入或要求熊、猎豹、枭兽形态**。
主要直伤指愤怒、星火术、月火术的主要直接伤害，不包括持续伤害、荆棘反伤或额外命中。
冷却最终不低于 0.2 秒，控制时长修正与装备共用 50% 加成上限。
回春术的自然结束与重新施放分开处理；延长预算按每次效果的初始持续时间计算。

## 构筑建议

- **自然消耗**：月火术、虫群，配跳伤频率和目标数。
- **控场区域**：纠缠根须、飓风，边移动边让敌人停留在伤害区。
- **续航防守**：回春术、荆棘术配防御属性；反伤不是免伤，仍应避免被围住。
