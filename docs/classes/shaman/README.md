# 萨满祭司：技能与天赋

[职业总览与通用规则](../README.md) · [项目首页](../../../README.md#职业介绍)

以闪电箭开局，结合弹跳、震击、图腾和近身闪电护盾。
图腾在当前位置自动攻击，不需要手动指挥，也没有原版四系图腾栏管理。

## 自动技能池

以下为 1 级定义基础值，未计装备、被动和技能升级。

| **闪电箭** `lightning_bolt` | 15 | 1.3 | 开局技能；24 码远程投射 |

## F：幽魂之狼

局内 5 级解锁，基础冷却 **15 秒**，移动速度提高 **60%**，持续 **6 秒**。
当前战斗逻辑实现的是移速增益，不承诺实际切换狼形态模型。

## 局外天赋

元素、增强、恢复各 8 个节点，共 24 个；最多 51 点，免费重置，下一局生效。
普通节点最多 5 点，终极节点最多 1 点；每树阶层依次为 0、0、1、2、3、4、5、6，
第 n 阶要求本树更低阶累计投入 5n 点。下表序号对应源码索引，5 点节点的效果均为**每级**数值。
**增强围绕闪电护盾与震击联动，不引入普通攻击、武器附魔或风怒自动攻击**。
图腾仍是无需天赋解锁的局内技能；恢复系强化自己的图腾阵地，不要求队友。
“闪电主要直伤”仅指闪电箭、闪电链，“震击主要直伤”仅指地震术、烈焰震击、冰霜震击的直接命中。
主要直伤不包括烈焰震击跳伤、图腾、闪电护盾或过载追加命中；节点明确指定后者时才可触发。
冷却最终不低于 0.2 秒；闪电护盾的频率修正与装备共用 200% 加成上限，
闪电链跳跃威力修正与装备共用 15 个百分点上限。

## 构筑建议

- **链式清群**：闪电链配额外跳跃、跳跃距离和弹跳伤害保留率。
- **图腾阵地**：灼热图腾、熔岩图腾，配持续时间、频率或范围；图腾不会跟随角色移动。
- **震击风筝**：烈焰震击、冰霜震击，利用幽魂之狼保持距离。
