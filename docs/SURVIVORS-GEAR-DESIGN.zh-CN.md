# Survivors 装备系统重构设计

本文记录 Survivors 装备系统的已确认产品规则。随机数值、换算系数、收益上限、触发概率、冷却、控制递减参数和品质区间均由数据配置维护，并通过 16 槽模拟与实战测试调优；本文不预设这些数值。

## 装备身份与槽位

装备名称是固定的基础身份。品质、随机属性和额外效果属于具体掉落实例，不能拼接进装备名称。同一基础装备可以有不同品质和不同随机结果。

| 分组 | 槽位 |
|---|---|
| 护甲与武器 | 头、肩、胸、手、腰、腿、脚、主手、副手 |
| 饰品 | 项链、披风、护腕、戒指×2、饰品×2 |

16 个槽位从一开始全部开放。每个新增槽位至少配置一个固定身份装备；新增槽位不增加角色外观，主副手继续沿用现有武器显示。

每个基础装备具有固定槽位和 1–2 项偏好主属性。偏好只影响随机权重，不保证该属性必出，也不排除其他属性或限制穿戴职业。物理/法术/混合职业倾向仅用于 Armory 提示与推荐，不参与战斗结算或穿戴限制：

| 倾向 | 职业 |
|---|---|
| 物理 | 战士、猎人、盗贼 |
| 法术 | 法师、牧师、术士 |
| 混合 | 圣骑士、萨满、德鲁伊 |

各职业有独立穿戴配置，但同一装备实例同一时间只能属于一个职业；跨职业装备会转移该实例。共享背包容量为 200 件。背包满时保留现有策略：淘汰最低品质的未穿戴装备；若没有未穿戴装备则拒收新掉落。

## 品质、属性与额外效果

保留 Common、Uncommon、Rare、Epic、Legendary、Primal 六档。每件装备按品质生成下列数量：

| 品质 | 随机属性数 | 技能强化/Proc 总数 |
|---|---:|---:|
| Common | 1 | 0 |
| Uncommon | 2 | 0 |
| Rare | 3 | 1 |
| Epic | 4 | 2 |
| Legendary | 5 | 3 |
| Primal | 5 | 4 |

五项主属性和次属性共用一个按权重抽取的属性池，不设置主/次属性配额。同件装备不重复同一属性；跨装备属性点线性相加。主属性包括力量、敏捷、耐力、智力、精神。次属性包括有独立玩法价值的防御（护甲、伤害减免）、暴击倍率、吸血、移动速度、技能冷却、移动技能冷却、范围、持续伤害频率、施法距离、回响、多目标、拾取范围、经验和运气等。

每个效果槽按品质权重从合法的技能强化或 Proc 候选中抽取。品质越高，Proc 权重越大；新掉落的 Legendary 和 Primal 在存在合法 Proc 候选时至少包含一个 Proc。单件装备内不重复同一个 `(目标技能, 强化种类)`，同名 Proc 也不重复；同一技能可以有不同种类的强化。

## 属性结算与技能类型

主属性点先跨装备相加，再通过统一换算表结算：

| 主属性 | 战斗收益 |
|---|---|
| 力量 | 物理伤害 |
| 敏捷 | 物理伤害、物理暴击率 |
| 耐力 | 最大生命、生命回复速度 |
| 智力 | 法术伤害、治疗效果、法术护盾 |
| 精神 | 法术暴击率 |

物理暴击只作用于物理效果；法术暴击作用于法术伤害、治疗和法术护盾。暴击倍率统一，暴击倍率本身可作为独立次属性。混合伤害按效果配置比例拆成物理与法术分量，分别计算属性加成并分别判定暴击，之后合并为一次技能命中结果。

每个技能效果必须显式标注物理、法术或混合类型；混合比例显式配置。伤害类型不能由职业或技能名称推断。Proc 的伤害、治疗和护盾也使用相同的显式类型与属性结算规则。玩家技能和 Proc 的治疗/法术护盾可以受到法术暴击影响。

主属性和次属性的最终收益都有上限。属性点、属性换算、品质区间、收益上限及各类 Proc/强化数值均由数据配置维护。Armory 同时显示原始属性点和计入上限后的实际收益变化。

## 技能强化

技能强化固定绑定一个满足兼容条件的具体技能，不随穿戴职业或当前构筑重新抽取。强化目标从全局兼容技能池抽取，并提高掉落来源职业技能的权重，但不排除其他职业技能；没有合法强化目标时，该效果槽改抽 Proc。

穿戴者没有或未解锁目标技能时，强化休眠，不限制装备穿戴。运行中，装备评分按当前构筑计算强化贡献；菜单中按该职业完整可获得的技能池作为基线。详情展示强化目标及当前是否生效。

## 装备触发效果（Proc）

Proc 是装备拥有的技能式效果，不占用玩家技能位。初始目录包括闪电链、击杀爆炸、元素持续伤害、治疗/护盾和控制（减速、眩晕）。闪电链从触发事件的敌人开始跳向附近敌人；击杀爆炸以被击杀敌人为中心；元素持续伤害和控制作用于触发事件的敌人；治疗和护盾作用于玩家。距离、目标数、伤害、持续时间等具体数值由配置调优。

每个 Proc 显式配置物理/法术/混合类型（适用于伤害、治疗和护盾）及触发条件。可用触发事件为玩家技能的正有效直接伤害、DoT 跳和玩家技能击杀；Proc 自身、回响复制伤害、治疗和护盾都不能触发其他 Proc。致命命中可以分别满足伤害 Proc 与击杀 Proc 的条件，但同一 Proc 对同一目标同一命中最多判定一次。不同名称的 Proc 可在同一事件中并发。

同名 Proc 的各装备实例分别掷触发概率，但共用当前 run 内的冷却；冷却只在成功触发后开始，卸下或重新装备不会重置。多个同名实例在同一事件中同时成功时，只执行效果最强的实例；相同强度按固定槽位顺序决胜。Proc 已产生的持续效果在卸下来源装备后持续至自然结束。

## 控制效果

Proc 控制复用现有敌人控制处理。玩家技能与 Proc 共享控制递减状态；每个敌人对 Slow、Root、Stun、Fear 分别计数。成功施加才推进相应递减层级；在最近一次成功施加后的可配置恢复窗口内没有新的成功施加时重置，免疫尝试不重启窗口。递减层级、持续时间缩放、免疫和恢复时间通过配置调优。

处理顺序为：先应用控制递减，再应用现有 Boss 规则，最后按现有非叠加规则合并状态。Boss 的 Slow 最多降低移动速度 25%，Root/Stun 持续时间为普通敌人的 30%，Fear 不作用于 Boss。状态不叠加时沿用现有合并方式：Slow 保留较强减速和较长计时，Root/Stun 保留较长计时。

## 掉落与 Armory

保留当前普通敌人总掉落率、Boss 品质权重、最终 Boss 的 Primal 奖励和 Luck 修正。首版先均匀选择 16 个槽位，再在所选槽位的基础装备身份中均匀选择；槽位和身份权重可配置。根据完整 16 槽填充速度的模拟与实战结果，再单独考虑调整掉落节奏。

Armory 将穿戴面板分为“护甲与武器”和“饰品”，保留装备与共享背包交互。详情展示属性点及其换算效果、技能强化目标、Proc 触发条件/概率/冷却/效果和当前装备对比；双槽对比同时展示两件装备并标出替换目标。Armory 可在菜单和暂停时使用，暂停时换装立即应用。

戒指和饰品双槽先填空槽；两个槽都已装备时，比较移除每件装备对当前整套配置造成的有效收益损失，移除损失较少者。评分考虑属性上限、当前职业/构筑的强化适用性和 Proc 期望贡献；菜单中使用职业完整可获得技能池作为强化评分基线，平分按固定槽位顺序处理。玩家明确点击装备后即执行，即使候选装备更弱也不额外阻止或二次确认；界面显示替换前后的属性与有效收益差值。

## 存档迁移

当前存档版本为 v3。新格式使用版本化迁移，不清空玩家装备。每次实际迁移前创建带版本/时间信息且不覆盖已有文件的旧档备份；备份失败时保留原档并报告错误。迁移写入成功后才替换正式存档。若旧基础装备/属性缺少显式映射，安全中止，不猜测、不丢弃装备，修齐映射后再重试。

迁移保留现有装备名称、品质、共享背包和九个旧槽位的职业穿戴关系；每个职业的七个新增槽位初始为空。旧通用伤害和暴击率按基础装备的显式映射迁为力量/智力或敏捷/精神；优先匹配该基础装备的偏好主属性，混合或无匹配情况逐件指定。旧最大生命和生命回复映射到耐力；兼容次属性（包括暴击倍率、护甲、伤害减免）保留。

同一旧属性映射到同一主属性时先换算成属性点并合并，再确定性补齐缺少的唯一属性。有效的旧技能强化保留；同一 `(目标技能, 强化种类)` 重复时保留贡献最大者。旧的空目标全局强化以稳定迁移种子绑定到一个兼容技能，并按掉落来源职业加权；无效或不兼容强化移除并记录诊断，不猜测替代目标。迁移后按新品质条数严格归一，缺少的属性/效果用确定性结果补齐。迁移的 Legendary/Primal 不强制替换兼容强化来满足 Proc 保底；Proc 保底仅约束新掉落。

## 平衡与验证方向

首轮数值配置完成后，使用完整 16 槽配置进行模拟，检查属性上限、技能/Proc 期望收益、饰品评分、职业差异和槽位填充速度，再通过实战测试调优。掉落总率与品质概率在测试证明有必要前保持不变。
